# Talent_intelligence_Stack - https://marfreeman.github.io/Talent_intelligence_Stack/

This file is a single-page HTML dashboard for a curated “Talent Intelligence Stack” directory of recruiting/sourcing tools.

What it does:

Presents a large, dark-themed landing page titled “Talent Intelligence Stack”
Shows a header with the project title, author attribution, and “Updated as of 01/04/2026”
Includes a search box and category filter buttons to browse tools by type
Renders a grid of tool cards, each with:
tool name
category label
short description
tags
buttons to copy the URL or open the tool
Supports live filtering:
search by tool name, description, or tags
filter by category such as Productivity, Learning, AI tools, OSINT, SERP, Engineering, Data, Intel, Verify, Outreach, etc.
Includes a “Export All Tools” button that copies the full list of unique tools to the clipboard
Displays a toast notification when a link is copied or export is completed
Uses Tailwind CSS and custom styling for a polished dark UI

No sign-up and free to use
